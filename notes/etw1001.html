Complete exam-prep: descriptive stats, inference, regression, interpretation

1. Descriptive statistics

Mean x̄ = Σx/n — sensitive to outliers.
Median — middle value; robust to outliers; prefer when skewed.
Mode — most frequent.

Sample variance s² = Σ(x − x̄)² / (n − 1)
Sample SD s = √s²

Use n−1 for sample variance (unbiased estimator of σ² under standard assumptions). Range = max−min; IQR = Q3−Q1.

Data: 5,7,9,11,13. Mean=9.
Deviations²: 16+4+0+4+16=40 → s²=40/4=10 → s=√10≈3.16

2. Probability basics

0 ≤ P ≤ 1. Addition/multiplication rules as taught. Normal distribution: empirical rule ~68% / 95% / 99.7% within 1 / 2 / 3 SD of mean (approx).

3. Inference

Parameter = population (μ, σ, p). Statistic = sample (x̄, s, p̂).

CI idea: x̄ ± critical value × SE. 95% CI: in repeated sampling, ~95% of such intervals capture the true mean. Do not say “P(μ in this interval)=0.95” after seeing the data (frequentist).

Hypothesis test steps:

  1. H₀ and H₁
  2. α (often 0.05)
  3. Test statistic
  4. p-value or critical value
  5. Reject or fail to reject H₀
  6. Business conclusion in words

Type I: reject true H₀. Type II: fail to reject false H₀. Power = 1 − β.

4. Simple linear regression

Ŷ = b₀ + b₁X

b₁ = estimated average change in Y for +1 unit X.
b₀ = predicted Y when X=0 (may be meaningless if X=0 is outside data range).
R² = fraction of sample variation in Y explained by X — not proof of causality.

Ŷ = 15 + 3.2X (X = advertising RM’000, Y = sales RM’000)
Slope: each extra RM1,000 advertising associated with ~RM3,200 higher sales on average.

5. Worked mini set

Data: 2,4,6,8,10. Mean=6. Σ(x−x̄)²=40. s²=40/4=10. s≈3.16.
Median=6. No single mode (all unique) or all equally frequent.

6. Checklist

  • □ Mean vs median when to use which
  • □ Sample SD formula with n−1
  • □ Parameter vs statistic
  • □ Type I / Type II
  • □ Interpret slope and R² without claiming causality
  • □ Write hypotheses and conclusions in words
Exam: Interpretation marks often exceed pure calculation marks.

STATISTICS • LEVEL 1

ETW1001 – Introduction to Statistical Analysis

Detailed notes: Descriptive statistics, probability, inference, regression, Excel focus.

1. Unit Overview

Covers the four analytics types (descriptive, diagnostic, predictive, prescriptive). Strong emphasis on interpreting results in a business context and using Excel.

2. Descriptive Statistics

Measures of Central Tendency

  • Mean – arithmetic average. Sensitive to outliers.
  • Median – middle value when ordered. Robust to outliers.
  • Mode – most frequent value.

Use median when data are skewed or contain extreme values.

Measures of Dispersion

Range = Max − Min
Sample Variance s² = Σ(x − x̄)² / (n − 1)
Sample Standard Deviation s = √s²

Other Useful Concepts

  • Percentiles and quartiles
  • Interquartile range (IQR) = Q3 − Q1
  • Z-score = (x − μ) / σ (how many SDs from the mean)

3. Probability Basics

  • Probability ranges from 0 to 1
  • Addition rule, multiplication rule
  • Common distributions: Binomial, Normal (bell-shaped, defined by μ and σ)

Empirical rule for Normal distribution: ~68% within 1 SD, ~95% within 2 SD, ~99.7% within 3 SD.

4. Inferential Statistics

Confidence Intervals

CI for mean (σ known): x̄ ± zα/2 × (σ / √n)

A 95% CI means: if we repeated the sampling process many times, approximately 95% of the intervals constructed would contain the true population mean.

Hypothesis Testing Steps

  1. State H₀ (null) and H₁ (alternative)
  2. Choose significance level α (commonly 0.05)
  3. Calculate test statistic
  4. Find p-value or compare with critical value
  5. Decide: reject H₀ or fail to reject H₀
  6. Interpret in business language

Type I error: Reject true H₀ (false positive).
Type II error: Fail to reject false H₀ (false negative).

5. Simple Linear Regression

Ŷ = b₀ + b₁X
  • b₀ = intercept (predicted Y when X = 0)
  • b₁ = slope (change in predicted Y for a one-unit increase in X)
  • R² = proportion of variation in Y explained by X (0 to 1)
Ŷ = 12 + 2.5X (X = advertising RM’000, Y = sales RM’000)
Slope 2.5 means: each additional RM1,000 of advertising is associated with RM2,500 higher sales on average.

6. Excel Skills to Master

  • AVERAGE, MEDIAN, STDEV.S, VAR.S
  • CORREL, Data Analysis ToolPak → Regression, Descriptive Statistics
  • Charts: histogram, scatter plot with trendline

7. Exam Tips

  • Always interpret numbers in context — “what does this mean for the business?”
  • State hypotheses clearly and write a conclusion in words.
  • Know when to prefer median over mean.
  • Practise reading regression output (coefficients, R², p-values).

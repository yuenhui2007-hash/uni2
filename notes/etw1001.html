ETW1001 – Introduction to Statistical Analysis

Descriptive analytics, probability, inference, regression and forecasting using Excel.

1. Unit Overview

Introduces the four types of analytics (descriptive, diagnostic, predictive, prescriptive) with a strong practical focus. You will learn to summarise data, handle uncertainty with probability, make inferences, build simple regression models and communicate results clearly. Excel is the main tool.

2. Key Definitions

Descriptive Statistics
Methods used to summarise and describe the main features of a data set (mean, median, mode, standard deviation, graphs).
Population vs Sample
Population = entire group of interest. Sample = subset selected for analysis. We use sample statistics to make inferences about population parameters.
Probability
A numerical measure of the likelihood that an event will occur, ranging from 0 to 1.
Confidence Interval
A range of values, calculated from sample data, that is likely to contain the true population parameter with a stated level of confidence (e.g., 95%).
Hypothesis Testing
A formal procedure to decide whether sample evidence supports or rejects a claim about a population parameter.
Simple Linear Regression
A statistical method that models the relationship between a dependent variable (Y) and a single independent variable (X) using a straight line.

3. Core Formulas & Concepts

Measures of Central Tendency

Mean (x̄) = Σx / n
Median = middle value when data is ordered
Mode = most frequent value

Measures of Dispersion

Variance (s²) = Σ(x – x̄)² / (n – 1)
Standard Deviation (s) = √variance
Range = Max – Min

Z-score

z = (x – μ) / σ

Confidence Interval for Mean (σ known)

x̄ ± zα/2 × (σ / √n)

Hypothesis Testing Steps

  1. State H₀ and H₁
  2. Choose significance level α (usually 0.05)
  3. Select test statistic and compute its value
  4. Find p-value or critical value
  5. Make decision and interpret in context

Simple Linear Regression

Ŷ = b₀ + b₁X
where b₁ = slope, b₀ = intercept

R² measures the proportion of variation in Y explained by X.

4. Worked Examples

Mean & SD
Data: 4, 6, 8, 10, 12
Mean = 8
Variance = [(4-8)² + (6-8)² + … + (12-8)²] / 4 = 10
SD = √10 ≈ 3.16
Interpretation of Regression
Ŷ = 2.5 + 0.8X (X = advertising spend in RM’000, Y = sales in RM’000)
Slope 0.8 means: for every additional RM1,000 spent on advertising, sales are expected to increase by RM800, on average.

5. Exam Tips

  • Know when to use mean vs median (skewed data → median).
  • Always interpret results in the business context – numbers alone are not enough.
  • Practise Excel: AVERAGE, STDEV.S, CORREL, Data Analysis ToolPak (Regression, Descriptive Statistics).
  • For hypothesis tests, clearly state the conclusion in words (“There is sufficient evidence…”).
  • Understand Type I and Type II errors.
